# レビュー件数フィールドの廃止方針

2026-08-10以降、Moilumの本番SSoT（`src/products.json`）と公開SPAデータは `reviews` を持ちません。

- 出典を商品単位で説明できないため、表示・並び順・ランキング・レーダー・自動コメント・コラム比較・JSON-LDには使用しません。
- `scripts/*candidates*.json` と旧取得スクリプトに残る `reviews` / `reviewCount` は、過去の取り込み作業を再現するための非公開レガシー資料です。本番ビルドは参照しません。
- `scripts/merge-editor-primary-source.mjs` は、候補データに旧フィールドがあっても本番SSoTへコピーしません。
- 新しい商品を追加するときは、レビュー件数やEC評価を `rating` の代替根拠として自動生成しないでください。

公開評価で使えるのは、出典を確認できる参考価格、主要成分、カテゴリ、掲載肌タイプ、掲載悩み分類、実使用情報の有無です。
